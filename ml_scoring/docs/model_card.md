# Model Card: Synthetic Credit Scoring v1

## Назначение

Локальная экспериментальная модель для демонстрационного MVP кредитного кабинета.

**Модель не предсказывает подтверждённую вероятность одобрения кредита реальным банком. Она воспроизводит статистические закономерности демонстрационной синтетической симуляции.**

Результат не должен использоваться для автоматического принятия кредитных решений.

## Данные и target

Модель обучена на синтетических заявках генератора v1.0. Target `approved` — Bernoulli-результат симуляции, а не реальное банковское решение или факт дефолта.

## Признаки

- `annual_revenue`
- `credit_history`
- `business_age_months`
- `loan_amount`
- `has_collateral`
- `loan_term_months`

Возраст исключён из модели и используется только в диагностическом аудите.

## Алгоритм и выбор

Выбрана Logistic Regression: небольшой выигрыш CatBoost на model-selection не подтвердился одновременно по ROC-AUC и Log Loss на независимой calibration-evaluation части, поэтому для MVP предпочтён более простой baseline.
Итоговый способ калибровки: **not_applicable**. Threshold: **0.5**.

Отдельная post-hoc калибровка итоговой Logistic Regression не применялась. Для CatBoost
исследованы исходные вероятности, sigmoid и isotonic; ни один калибратор не улучшил одновременно
Brier Score и Log Loss на независимой calibration-evaluation части.

## Калибровка и подгруппы

Итоговая калибровка: `not_applicable`. Диагностика выполнена по кредитной истории, сроку бизнеса, отношению кредита к выручке и возрасту. Возрастной анализ не является доказательством справедливости.

Первоначальный test был открыт один раз до исправления правила выбора семейства модели.
Исправление использовало только сохранённые validation-метрики, без повторного чтения test CSV и
без пересчёта test-прогнозов. Поэтому test-результат нельзя считать полностью независимым
относительно финальной маркировки артефакта.

## Ограничения использования

- Только доверенный локальный inference на данных той же схемы.
- Нельзя использовать для реальных кредитных решений, pricing или отказов.
- Нельзя трактовать вероятность как оценку реального банка.
- Нужны реальные данные и независимая валидация до любого product use.
- Joblib-артефакты нельзя загружать из недоверенного источника.
