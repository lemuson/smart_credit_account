# Демо Экспресс

Это полностью синтетический продукт конкурсного MVP. Он используется только для проверки
сценариев ассистента и не отражает действующие условия Альфа-Банка.

Продукт моделирует финансирование текущих расходов индивидуального предпринимателя. Для заявки
нужна выписка по расчётному счёту. Числовые параметры продукта должны запрашиваться через backend.

Если продукт не прошёл формальные фильтры, ассистент должен объяснить причины на основе результата
инструмента, не делать выводов о платёжеспособности пользователя и не предлагать обход проверок.
