# Демо Оборотный капитал

Это вымышленный продукт для демонстрации конкурсного прототипа. Он не является предложением
Альфа-Банка, публичной офертой или обещанием одобрения.

Продукт предназначен для закупки товаров и пополнения оборотных средств. Формальная проверка
учитывает срок работы бизнеса, организационно-правовую форму, сумму и срок. Актуальные числовые
условия ассистент обязан получать из API backend, а не из этого справочного текста.

Для подготовки заявки обычно нужны налоговая декларация и выписка по расчётному счёту. Выписка
помогает проверить движение средств, а декларация — согласованность указанных финансовых данных.
Наличие документов не гарантирует одобрение.
