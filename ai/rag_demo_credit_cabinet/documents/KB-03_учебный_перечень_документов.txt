ID документа: KB-03
Название: Учебный чек-лист документов для ИП и ООО
Версия: 1.0
Категория: справочник документов
Статус: УЧЕБНЫЙ ДЕМОНСТРАЦИОННЫЙ МАТЕРИАЛ — НЕ ОФИЦИАЛЬНЫЕ ПРАВИЛА БАНКА

Внимание: перечисленные ниже комплекты придуманы для демонстрации RAG. Они НЕ являются реальными обязательными требованиями банка. Для конкретного кредитного продукта актуальный список должен возвращать Backend Tool get_required_documents.

1. Общий учебный комплект
В учебном примере общий комплект состоит из анкеты с параметрами заявки, подтверждения полномочий заявителя и финансовых сведений о деятельности. Пример финансовых сведений — выписка по расчётному счёту за последние шесть месяцев. Шесть месяцев — параметр учебного сценария, а не действующее требование банка.

2. Учебный перечень для ИП без залога
Для сценария ИП без залога используются четыре позиции: (1) заполненная анкета, (2) документ, удостоверяющий личность заявителя, (3) подтверждение регистрации ИП или актуальные регистрационные сведения, (4) пример выписки по расчётному счёту за последние шесть месяцев. Документы по залогу в этот сценарий не входят.

3. Учебный перечень для ООО без залога
Для сценария ООО без залога используются пять позиций: (1) заполненная анкета, (2) регистрационные сведения юридического лица, (3) документ о полномочиях подписанта, (4) финансовая отчётность за доступный отчётный период, (5) пример выписки по расчётному счёту за последние шесть месяцев.

4. Если предполагается залог
К учебному комплекту может добавляться описание предмета обеспечения и подтверждение права распоряжения им. Для конкретных объектов документы могут различаться. Без подтверждения Backend нельзя утверждать, что банк принимает определённый объект в залог.

5. Чего не делает RAG
RAG не проверяет подлинность документов и не подтверждает успешную загрузку файла. Фактическая комплектность заявки определяется бизнес-логикой Backend. Если пользователь спрашивает «Какие документы обязательны именно по моему кредиту?», нужно обратиться к get_required_documents, а этот учебный чек-лист использовать только как пример.

6. Контрольные вопросы
«Какие четыре позиции в демонстрационном комплекте ИП без залога?», «Чем учебный комплект ООО отличается от ИП?», «За какой период приведён пример выписки?». Источник: KB-03.
