ID документа: KB-01
Название: Назначение демонстрационной базы знаний и приоритет источников
Версия: 1.0
Категория: правила демонстрации RAG
Статус: УЧЕБНЫЙ ДЕМОНСТРАЦИОННЫЙ МАТЕРИАЛ — НЕ ОФИЦИАЛЬНЫЕ ПРАВИЛА БАНКА

1. Для чего предназначены эти материалы
Документы KB-01 — KB-07 созданы специально для проверки поиска по знаниям (RAG) в прототипе «Умный кредитный кабинет предпринимателя». Они отражают только учебные сценарии и поясняют термины. Эти документы не описывают действующие условия, ставки, решения или обязательные требования Альфа-Банка либо другого реального банка.

2. Разделение источников
Точные условия существующих кредитных продуктов, текущие суммы, сроки, процентные ставки, персональный профиль организации, список документов для конкретного продукта и реальный статус заявки нужно получать из Main Backend через предназначенные для этого HTTP Tools. RAG-документы используются для общего объяснения терминов и демонстрационного порядка действий. При конфликте учебного текста и проверенного ответа Backend приоритет имеет Backend. Если Backend недоступен, нельзя выдавать сведения из учебного документа за актуальный персональный статус или за актуальные условия продукта.

3. Что проверяется в демо
RAG должен находить нужный фрагмент по смыслу, возвращать идентификатор или название документа как источник (если текущий API поддерживает sources), не придумывать несуществующие страницы и корректно сообщать об отсутствии данных. В тестовых запросах рекомендуется спрашивать: «Что относится к учебному чек-листу для ИП?» или «Какое отличие ML-оценки от решения банка описано в KB-06?». Ответ должен быть привязан к содержимому соответствующего документа.

4. Ограничения
Не использовать эти материалы как юридическую, налоговую или финансовую консультацию. Не обещать одобрение кредита. Не присваивать этим материалам реквизиты или статус нормативного документа. Все числовые параметры, если они встречаются, являются только примерами конкретного учебного сценария.
